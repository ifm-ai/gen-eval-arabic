# GPU packages. Install them with:
#
#   python install_cuda.py
#
# The script reads "CUDA Version" from nvidia-smi and adjusts this file.
# A driver that reports 13.0 installs every "toolkit" package as >13.0,<13.2
# and installs PyTorch from https://download.pytorch.org/whl/cu130.
# nvidia-cuda-nvdisasm is the exception: CUTLASS 4.6.2 needs >=13.3,<14.
#
# Comments after a package name are read by install_cuda.py:
#   toolkit    version follows the driver CUDA version
#   torch      PyTorch wheel; the +cu130 tag follows the driver
#   cu-major   package name uses cu13 on CUDA 13 and cu12 on CUDA 12
#   cu12-only  installed only when the driver reports CUDA 12
#   cu13-only  installed only when the driver reports CUDA 13
